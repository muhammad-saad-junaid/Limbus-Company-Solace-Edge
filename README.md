## 🎯 Core Combat Enhancements

### ⚡ SP Flow Optimization
The mental fortitude system is a fickle beast. LUMINARY EDGE provides real-time SP adjustment that keeps your sinners in the **optimal confidence zone** — not so high that they become reckless, not so low that they falter at critical moments. This isn't about spongebathing everything; it's about maintaining a **psychological rhythm** that matches your combat tempo.

### 🛡️ Defensive Stability Matrix
Our proprietary **Guardian's Calculus** engine continuously evaluates incoming threat patterns and adjusts defensive parameters dynamically. This manifests as:
- Reduced stagger vulnerability windows
- Enhanced resistance profile during multi-wave encounters
- Adaptive armor rating that responds to enemy attack signatures

### ⚔️ Offensive Amplification Protocol
When you decide to strike, LUMINARY EDGE ensures your blows land with **authoritative precision**:
- Consistent damage output amplification (configurable percentage)
- Critical opportunity windows extended by milliseconds that matter
- Stagger threshold calculation assistance for boss encounter phases

### 🎭 Sinner Attribute Harmonization
Each of the twelve sinners has unique stat distributions. LUMINARY EDGE reads your team composition and applies a **balanced attribute enhancement** — not overpowering, but smoothing out the rough edges that make solo runs feel unfairly weighted. Strength, agility, tenacity, and perception get modest, elegant boosts that make the experience feel *intended by the game designers*.

## ⚙️ Installation Philosophy

Getting LUMINARY EDGE onto your system is designed to be as **non-interference-based** as possible. We follow a "download-and-inhabit" approach rather than forced integration methods. The package is self-contained, requires no additional runtime dependencies beyond what Windows already provides, and is designed to coexist peacefully with the game process without raising the system's threat-detection hackles.

- Windows 10 (Build 19041+) or Windows 11
- 8GB RAM minimum (16GB recommended for overlay comfort)
- 150MB available storage
